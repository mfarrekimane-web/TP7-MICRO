# TP7 - Microservice

## Description
Travail pratique n°7 : gestion des étudiants avec Spring Boot (API REST, MySQL, tests unitaires, Swagger).

## Technologies
- Java 21
- Spring Boot 4
- Spring Data JPA / MySQL
- Maven
- JUnit 5 / Mockito
- Springdoc OpenAPI (Swagger)

## Lancement
1. Cloner le dépôt : git clone https://github.com/mfarrekimane-web/TP7-MICROSERVICE.git
2. Créer la base MySQL et adapter application.properties
3. Ouvrir le projet dans IntelliJ et lancer StudentManagementApplication
4. Swagger : http://localhost:8080/swagger-ui.html
