# TP7 : Student Management (Microservice)

## Description
Microservice de gestion des étudiants. Décris ici en une ou deux phrases ce que fait ton service (par exemple : CRUD sur les étudiants avec Spring et MySQL).

## Structure du dépôt
- [student-management](./student-management) : code source
- [captures](./captures) : captures d'écran de l'exécution

## Exécution
1. Démarrer la base de données (MySQL)
2. Adapter la configuration (utilisateur, mot de passe) si besoin
3. Lancer l'application (par exemple `mvn spring-boot:run` ou la classe principale)
